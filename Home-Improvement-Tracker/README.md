# Home-Improvement-Tracker
Overview

The Home Improvement Tracker helps you create projects (e.g., "Kitchen Remodel", "Bathroom Repair"), add tasks and sub-tasks, track materials and estimated vs actual costs, set target dates, and mark progress. It provides a consolidated view of all active and completed projects so you can manage time and budget effectively.

Netlify - https://home-improvement-tracker.netlify.app/

Key Features

Create and manage multiple projects (name, description, start/end date)

Add tasks and subtasks with due dates and priority

Track materials with quantity and price (estimated vs actual)

Expense tracking per project (auto-calc totals)

Mark progress with status (To-do / In progress / Done)

Search & filter projects and tasks (by status, priority, date)

User authentication (optional) to keep personal projects private

Responsive UI for mobile and desktop

Export or generate PDF summary of a project (optional)

Tech Stack

Frontend: React (Vite) or Create React App

Styling: CSS / Tailwind CSS / Chakra UI (choose one)

Backend / Realtime DB: Firebase Realtime Database or Firestore (optional)

Authentication: Firebase Auth (optional)

Deployment: Vercel / Netlify / GitHub Pages

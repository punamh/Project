# 🍲 Recipe App

This is a **Recipe Search Application** built with **React.js**.  
It allows users to search for recipes and view details such as images, ingredients, and instructions.  
The project was created to practice **React hooks** and **API integration**.

---

vercle - https://recipe-app-sigma-sooty.vercel.app/favorites

## 🌟 Features
- Search recipes by keyword  
- Display recipe details with images  
- Responsive card layout  
- API integration using **Axios**  
- Built with **React functional components**  

---

## 🛠️ Tech Stack
- **React.js**  
- **Axios** (for API requests)  
- **CSS3** (for styling and responsive design)
